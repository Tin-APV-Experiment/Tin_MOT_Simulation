# Tin_MOT_Simulation

This repository contains all raw data generated from the Optical Bloch Equation simulation software developed by T.K. Langin for molecular laser cooling and adapted by G. Zheng and J. Wang for studying laser slowing, laser cooling, and magneto-optical trapping of tin (Sn) atoms for a future atomic parity violation (APV) experiment. The repository also includes the Matlab code used to analyze the raw data (e.g. plot acceleration heat maps and curves, calculate slowing efficiency, calculate MOT temperature and size).

Jianwei's files contain his simulation runs for red MOT, compressed red MOT (cMOT), blue MOT, and conveyor belt blue MOT (CB MOT). The cMOT and CB MOT results were used for the tin laser cooling and trapping paper.

Geoffrey's files contain his simulation runs for red MOT, compressed red MOT, and white light slowing (WLS). The red MOT, cMOT, and WLS results were used for the tin laser cooling and trapping paper.
